# LearnFlow 리뷰 조회 후속 개선 검증

기존 작성자 일괄 조회 이후 남아 있던 수강 정보 반복 조회를 제거한 로컬 실험입니다. 프로젝트 당시 병합된 변경이나 운영 서비스 적용 결과와는 구분합니다.

## 문제와 변경

리뷰의 작성자 ID를 읽는 과정에서 지연 로딩된 수강 정보를 리뷰마다 조회했습니다. 기존 작성자 일괄 조회는 유지하고, 리뷰 조회 메서드에 `@EntityGraph(attributePaths = "enrollment")`를 추가했습니다. 응답에 필요한 단일 연관관계만 함께 조회하며 조회 API의 반환 형식은 바꾸지 않았습니다.

| 조회 리뷰 수 | SQL 변경 전 → 후 | 처리 시간 변경 전 → 후 | 시간 감소율 |
| --- | --- | --- | --- |
| 10건 | 15회 → 5회 | 8.51ms → 5.47ms | 35.7% |
| 20건 | 25회 → 5회 | 11.19ms → 4.93ms | 55.9% |
| 50건 | 별도 SQL 진단 없음 | 21.63ms → 5.07ms | 76.5% |

SQL은 별도 진단 실행의 요청당 횟수입니다. 시간은 각 회차 평균 3개의 중앙값이며, 감소율은 반올림 전 값으로 계산했습니다. 기존 작성자 조회 개선의 23%와 합산하지 않습니다.

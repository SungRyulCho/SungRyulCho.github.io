About

문제를 데이터 흐름과 운영 상태로 바라봅니다

단순히 기능을 만드는 것보다, 어떤 데이터가 언제 저장되고 어떤 예외가 사용자 경험을 깨뜨리는지 끝까지 추적하는 개발 방식을 선호합니다.

  • 동시성 제어

    Redisson 분산 락과 트랜잭션 분리로 동일 카드 중복 저장 문제를 제어했습니다.

  • 인증/인가

    JWT, Refresh Token, Redis 블랙리스트, 관리자 로그인 제한 흐름을 구현했습니다.

  • 쿼리와 API

    최신 카드 조회를 윈도우 함수 기반 벌크 쿼리로 개선하고 API 응답 구조를 정리했습니다.

  • 제품형 MVP

# 조성률 Backend Portfolio

기존 단일 페이지 구성과 네이비·시안 테마를 유지한 HTML / CSS / JavaScript 포트폴리오입니다.

## 구성

- About: 강점 소개와 API/DB/OPS 개발 분야 요약, 졸업 학력, 쿠팡 상품 데이터 검수/보고/유관부서 협의 업무
- Skills: 기존 6개 카드에 기술명과 직접 수행 가능한 작업 범위를 표시 (구체적인 프로젝트 사례는 Work에 유지)
- Work: DEKK, LearnFlow, Vench AI (필터, 담당 업무, 문제 → 해결 방안 검토 → 해결·개선 상세, GitHub 링크)
- Education: 원티드랩 수료, 경기 AI 멤버십 수강 중, 정보처리기사 필기 합격, 팀 수상
- Contact: 이메일 링크·복사, GitHub, Velog

2026-09-27 기준 완성된 이력서 내용을 반영했습니다. 교육 과정 전체를 이미 숙달한 기술로 표시하지 않으며, 정보처리기사는 필기 합격과 실기 준비 중 상태를 구분합니다. 쿠팡은 프로젝트가 아닌 경력에만 남겼습니다.

## 로컬 확인

별도 빌드나 패키지 설치가 필요 없습니다. 저장소 폴더에서 정적 웹 서버로 확인할 수 있습니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

http://127.0.0.1:8080 에 접속합니다. HTML 직접 열기도 가능하지만 이메일 복사 기능은 브라우저의 보안·권한 설정에 따라 제한될 수 있습니다. 복사 실패 시 안내 문구와 이메일 링크가 유지됩니다.

## 확인할 동작

정적 회귀 검사: `python3 tests/check_site.py` (추가 패키지 불필요)

- 모바일 메뉴 열기/닫기, Escape 키, 메뉴 선택 후 자동 닫힘
- 프로젝트 필터와 필터로 숨겨진 프로젝트의 직접 링크
- 세 프로젝트의 담당 업무와 개선 사례는 각각의 버튼으로 같은 팝업을 사용 (원문 전체 유지, 중첩 팝업 없음)
- 담당 업무는 차분한 색의 버튼, 개선 사례는 강조색 버튼으로 항상 표시; 업무 팝업에는 사례 선택 탭 없이 전체 목록 표시
- 담당 업무와 개선 사례 팝업 모두 현재 내용에 맞는 높이로 표시하고 화면 한도를 넘을 때만 본문 스크롤
- JavaScript 또는 팝업 지원이 없으면 두 내용 모두 기본 펼침 방식으로 확인 가능
- 키보드로 문제 해결 상세 열기/닫기
- 모든 프로젝트의 동일한 상세 팝업, 제목과 본문 구분, 닫기/Escape/배경 클릭 후 각 버튼과 원래 스크롤 위치 복귀
- DEKK 네 사례, LearnFlow 세 사례, Vench AI 세 사례 전환과 좌우 방향키/Home/End
- LearnFlow: AI 작업 연결, 리뷰 조회 개선, 배포 과정 개선 / Vench AI: 진행 및 실패 대응, 음성 입력 처리, 감정 통계 개선
- 기본 카드에는 담당 업무/개선 사례 버튼과 문구 옆 화살표 표시; 전체 GitHub 저장소는 개선 사례 팝업 상단의 프로젝트명 옆에 테두리가 있는 보조 링크로 표시
- 사례별 PR/코드 링크는 본문 아래에 유지; 업무 팝업에는 전체 저장소 링크를 표시하지 않음
- 팝업의 320px 모바일 너비와 데스크톱 너비, 긴 본문 스크롤 중에도 유지되는 사례 메뉴와 닫기 버튼
- 모든 사례 직접 링크와 JavaScript 미사용 시 기본 펼침 유지 (본문, 기여 범위 안내와 근거 링크는 하나의 원본 사용)
- 모든 메뉴의 섹션 이동, 맨 위로 이동, 이메일 복사
- 320px부터 데스크톱까지 가로 넘침 없이 표시

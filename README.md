# 조성률 포트폴리오

프로젝트의 담당 역할과 문제 해결 경험을 정리한 개인 포트폴리오입니다.

[포트폴리오 바로가기](https://sungryulcho.github.io/)

## 사용 기술

HTML, CSS, JavaScript로 구성하고 GitHub Pages로 배포합니다.

## 프로젝트 구조

```text
포트폴리오
├── index.html       페이지 구성과 프로젝트 내용
├── css/
│   └── style.css    디자인과 반응형 레이아웃
├── src/             메뉴, 프로젝트 필터, 이미지 전환, 상세 팝업
├── images/          프로필과 프로젝트 화면 이미지
└── tests/           페이지 구조와 기능 검사
```
